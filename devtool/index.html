Inside the workshop

Inspect your workspace with DevTools

Inspect stored data, signed changes, query plans, and performance inside your app. Tools for understanding what your local-first software is actually doing.

Start with the docs ↗ Read the source ↗

Every panel, one keystroke away

Data

Query and browse every node in the store on the same grid your app ships with.

  • Live query-plan inspector
  • Inline editing with per-cell permissions
  • Sort, filter, hide columns per schema

Changes

A live, Lamport-ordered feed of the CRDT change log — every create, update, and delete.

  • Filter by change type or node
  • Inspect the full change payload
  • Follow remote changes as they sync

Performance

Cold-start boot timeline, live FPS and heap, storage status, and active query counts.

  • Boot waterfall by phase
  • Frame budget + heap sampling
  • Active useQuery / useMutate subscriptions

Logs

Toggle debug channels (sync, sqlite, query, boot) and search the captured console buffer.

  • Per-channel on/off, persisted
  • Level filter + full-text search
  • Pause, clear, copy

Seed

Populate a realistic demo workspace across every content type — idempotent and scalable.

  • Converge / accrete / reseed modes
  • Small → large volume knob
  • Per-domain toggles (CRM, docs, …)

The Data panel is the same GridSurface + useQuery your app ships with — so what you debug is exactly what you build.

Turn it on

One provider. Dev-only by default.

main.tsx 
import { XNetDevToolsProvider } from '@xnetjs/devtools'

<XNetDevToolsProvider>
  <App />
XNetDevToolsProvider>

// Press ⌘⇧D (Ctrl+Shift+D) to open. Tree-shakes to zero in production.
