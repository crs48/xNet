A heads-up about this beta

Mac and Windows may warn you about an unverified developer. These builds are self-signed, not Apple-notarized or signed by a verified Windows publisher. Downloads and updates have xNet signatures.

Desktop only for now. iOS, Android, and Windows/Linux ARM aren’t available yet.

A few small steps

Settle in.

Install xNet, choose a name, and invite someone you’d like to share it with.

Updates come to you.

While the app is open, verified updates download in the background. Choose Restart to update when you’re ready.

Install on macOS+

Open the disk image and drag xNet Community into Applications. Eject the image, then open the app from Applications.

If macOS blocks it because the developer is unverified, review the warning in System Settings → Privacy & Security. Use Open Anyway only if you trust this beta. You don’t need to turn off Gatekeeper.

To find your processor, open Apple menu → About This Mac. Choose Apple silicon for an Apple M-series chip, or Intel for an Intel processor.

Install on Windows+

Run the downloaded installer. SmartScreen may say the publisher is unknown; review the source before choosing More info → Run anyway. Managed computers may block unverified installers.

The installer will offer WebView2 if it isn’t already installed.

Install on Linux+

Ubuntu 24.04 is the tested baseline. For the Debian package, use your package manager so it resolves GTK and WebKit dependencies:

sudo apt install ./xnet-community-VERSION-linux-x64.deb

For AppImage, mark the file executable and open it. AppImage requires FUSE 2 and a compatible distribution; it does not make older Linux libraries compatible.

Updating a system package may ask for administrator authorization.

Before you invite your friends

  • Keep an authorized peer online for history and media. The server doesn’t store private chat history.
  • The room owner must be online for new messages. Other members can share history with permission lasting up to five minutes.
  • There’s no account recovery or automatic import from the retired Electron app.
  • The group protocol doesn’t yet have a forward-secret ratchet. This beta isn’t ready for highly sensitive conversations.
