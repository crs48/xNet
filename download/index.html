An independent, self-signed beta

These builds aren’t Apple-notarized or signed by a verified Windows publisher. Your computer may warn you before opening them. Downloads and automatic updates have xNet signatures; that is separate from operating-system approval.

iOS, Android, and ARM versions of Windows and Linux aren’t available yet.

Install once. Updates come to you.

On a Mac

Open the disk image and drag xNet Community into Applications. Eject the image, then open the app from Applications. If macOS blocks it because the developer is unverified, review the warning in System Settings → Privacy & Security. Use Open Anyway only if you trust this beta. You don’t need to turn off Gatekeeper.

On Windows

Run the downloaded installer. SmartScreen may say the publisher is unknown; review the source before choosing More info → Run anyway. Managed computers may block unverified installers. The installer will offer WebView2 if it isn’t already installed.

On Linux

Ubuntu 24.04 is the tested baseline. For the Debian package, install with your package manager so it resolves GTK and WebKit dependencies:

sudo apt install ./xnet-community-VERSION-linux-x64.deb

For AppImage, mark the file executable and open it. AppImage requires FUSE 2 and a compatible distribution; it does not make older Linux libraries compatible.

While the app is open, it checks for updates and downloads verified builds in the background. Choose Restart to update when you’re ready. Linux system packages may ask for administrator authorization.

Before you invite your friends

  • Keep an authorized peer online for history and shared media. The server doesn’t keep a copy of private chat history.
  • The room owner must be online for new messages. Another member can share history with permission that lasts up to five minutes.
  • There is no account recovery or automatic import from the old workspace.
  • The group protocol doesn’t yet have a forward-secret ratchet. This beta isn’t ready for highly sensitive conversations.

More detail in the beta guide. The retired Electron app is a separate product.
